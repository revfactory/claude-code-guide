# Claude Code Overview

## Get Started in 30 Seconds

Prerequisites: [Node.js 18 or newer](https://nodejs.org/en/download/)

```bash
# Install Claude Code
npm install -g @anthropic-ai/claude-code

# Navigate to your project
cd your-awesome-project

# Start coding with Claude
claude
```

## What Claude Code Does for You

- **Build features from descriptions**: Tell Claude what you want to build in plain English. It will make a plan, write the code, and ensure it works.
- **Debug and fix issues**: Describe a bug or paste an error message. Claude Code will analyze your codebase, identify the problem, and implement a fix.
- **Navigate any codebase**: Ask anything about your team's codebase, and get a thoughtful answer back. Claude Code maintains awareness of your entire project structure and can find up-to-date information.
- **Automate tedious tasks**: Fix lint issues, resolve merge conflicts, and write release notes in a single command.

## Why Developers Love Claude Code

- **Works in your terminal**: Meets you where you already work, with the tools you already love.
- **Takes action**: Can directly edit files, run commands, and create commits.
- **Unix philosophy**: Composable and scriptable. Example: `tail -f app.log | claude -p "Slack me if you see any anomalies"`
- **Enterprise-ready**: Offers enterprise-grade security, privacy, and compliance.
